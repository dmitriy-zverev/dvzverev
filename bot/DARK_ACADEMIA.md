# Конэсанс: литературные публикации

Проект `dark-academia` в `service.json` публикует в VK-сообщество `194579254` (@vosconnaissances). Расписание: 10:00 — только текст, 18:00 — текст с GIF, Europe/Moscow. Тестовые направления отсутствуют в активном конфиге. Telegram используется только для сообщений о сбоях.

Ключ хранится в локальном игнорируемом `.env`: `VK_DARK_ACADEMIA_ACCESS_TOKEN`; ID — `VK_DARK_ACADEMIA_GROUP_ID`. История: `data/projects/dark-academia/state.json`. Секреты не включаются в образ или Git.

Промпт: `prompts/dark-academia.md`. Проверенные цитаты, авторство и ссылки на тексты: `literary-quotes.mjs`. Модель генерирует только оригинальное дополнение из 2–5 абзацев. Каталог содержит 12 цитат из 10 произведений. Русская и зарубежная литература чередуются; выбор учитывает недавние произведения, авторов и цитаты. Зарубежные фрагменты сверены с оригиналами Project Gutenberg, перевод редакции явно указан в подписи. Ориентир длины продолжения — примерно 500 символов, без отклонения ответа за меньший или больший объём; модель получает четыре последних опубликованных текста для разнообразия. Для длительного ведения каталог нужно расширять. Примеры старых постов пока не были доступны, поэтому промпт опирается на описание владельца.

Подтверждённые временные ошибки повторяются ограниченно с задержкой. При неизвестном результате отправки пост получает `uncertain` и автоматически не повторяется. Ошибка уведомления не повторяет публикацию. Невалидный ответ модели повторяется до трёх попыток. Ошибки ключа или прав приостанавливают соответствующий сервис.

```sh
docker compose -f bot/compose.yaml exec poster node bot/run.mjs --validate-config
docker compose -f bot/compose.yaml exec poster node bot/run.mjs --generate-preview
docker compose -f bot/compose.yaml exec poster node bot/run.mjs --status
```

Превью оплачивает запрос к модели, но не публикует. Бюджеты в конфиге пока декларативны и не являются жёстким лимитом расходов.

## Вечерняя GIF-обложка

`prompts/dark-academia-gif.md` содержит визуальный промпт владельца. Модель текста выбирает сцену по готовому посту; Seedance 1.5 Pro создаёт четырёхсекундное видео 720p без звука. FFmpeg превращает первые три секунды в шестисекундный цикл вперёд-назад, 1280×720, до 10 MB. Сжатие адаптирует частоту кадров (8, 6 или 4 кадра/с), палитру и детализацию, сохраняя итоговые размеры. Это гарантирует совпадение первого и последнего кадров; художественная естественность движения зависит от результата модели.

Задание и стоимость сохраняются рядом с GIF в `images/*.gif.video.json`. Планировщик проверяет готовность раз в 30 секунд, не создавая новый платный запрос после перезапуска. Неопределённый результат отправки задания провайдеру не повторяется. Ошибки генерации, скачивания, конвертации и загрузки GIF повторяются до трёх попыток с задержкой 30/60 секунд. Ожидание рабочего задания не считается попыткой. Подтверждённо проваленное задание Seedance заменяется новым заданием той же модели, максимум три; загрузка и конвертация повторяют уже оплаченное видео. При исчерпании попыток выходит текстовый пост, а ошибки уходят в Telegram. Ожидание одного задания ограничено 15 минутами. Потерянный ответ на создание задания не повторяется, поскольку оно могло уже стать платным. VK получает GIF как документ через ключ сообщества, затем текст и вложение передаются одним `wall.post`.

Длительность генерации может сдвинуть вечернюю публикацию на несколько минут после 18:00. Утренний слот не вызывает API изображений или видео. Расписание вложения сохраняется в записи поста и не пересчитывается при повторе позднее.

## Резервные модели текста

Порядок: `qwen/qwen3-32b`, `qwen/qwen3.5-flash-02-23`, `deepseek/deepseek-v4.1-flash`. `providers.budget-editor.model` и `fallbackModels` задают последовательность. У планировщика всего три сохранённые попытки на слот — по одной на модель; превью использует ту же последовательность. Ошибки API и невалидный литературный ответ переключают модель. Общая ошибка ключа, баланса или доступа (401/402/403) приостанавливает источник: смена модели не исправляет эти ошибки. После трёх неудач текст не публикуется, владелец получает уведомления.

Модель и номер попытки сохраняются в истории ошибок и отображаются в уведомлении. При следующем слоте цепочка начинается с основной модели. Для GIF остаётся один Seedance 1.5 Pro; статичный кадр перед видео пока отдельно не генерируется.
