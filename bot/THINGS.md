# Вещи — кстати

Сообщество: https://vk.ru/veshi_kstati_tut, ID 242058626, проект `things`.
Только ключ сообщества, env `VK_THINGS_ACCESS_TOKEN` и `VK_THINGS_GROUP_ID`.

Расписание по Москве: 10:00 — текст, 18:00 — текст с GIF. Три текстовые модели
в общей цепочке; отдельная редакторская проверка перед публикацией. Семь типов
постов чередуются по истории, последние темы и тексты передаются редактору.
Основная модель — Qwen3.5 Flash, резервные — Qwen3 32B и DeepSeek V4.1 Flash.

Пока нет товарных данных: только редакционные бытовые сценарии, без цен,
ссылок, конкретных брендов и заявлений о тестировании товаров. Краткий формат
JSON нужен для проверки; читателю отправляется только готовый текст с абзацами.
Длина — ориентир 500–1000 знаков, без жёсткого нижнего порога.

Основной текстовый промпт и полное визуальное ТЗ сохранены из пользовательского
файла в `prompts/things-editor.md` и `prompts/things-gif.md`. Для Seedance
используется компактный `prompts/things-video.md`; сцену выбирает текстовая
модель по главному бытовому сценарию. Сейчас используется text-to-video → GIF,
не image-to-video. Когда появятся реальные товары и их фотографии, image-to-video
и источник фактических товарных данных потребуют отдельной интеграции.

Ошибки, backoff, уведомления владельцу, аналитика и расходы работают как у
остальных проектов. GIF: до трёх попыток, затем отправка текста без вложения.
LLM-проверка снижает риск плохой редакции, но не заменяет проверенные карточки
товаров и не является гарантией фактической точности.

сервера успешна. Пробные тексты генерировались без публикации.
