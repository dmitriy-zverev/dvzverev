# Код на подумать

VK: https://vk.ru/kod_na_podumat, ID 242034586. Проект `code-to-think` использует прежний ключ `VK_ACCESS_TOKEN`; идентификатор хранится в `VK_CODE_TO_THINK_GROUP_ID`. Отдельная история: `data/projects/code-to-think/state.json`. Telegram — только для ошибок. Медиа выключены.

Полный редакционный промпт владельца: `prompts/code-to-think.md`. Основная модель и два резервных — общий провайдер `budget-editor`. Дополнительную техническую проверку выполняет Qwen3.5 Flash (`generation.reviewModel`). Посты выводятся обычным текстом без оформления старого дайджеста, эмодзи и служебных метаданных. Ориентир — примерно 500 символов; необходимые условия и код могут увеличить объём.

Расписание по Москве:

- Понедельник–суббота, 12:00: новая задача.
- Понедельник, пятница и воскресенье, 18:00: разбор ранее опубликованной задачи.
- Среда, 18:00 и воскресенье, 12:00: редакционный evergreen-пост.

Всего 11 слотов в неделю. Разбор берётся из сохранённого решения старейшей опубликованной задачи, которая ещё не разобрана, и содержит ссылку на условие. Задачи текущего дня не разбираются. Если подходящей задачи пока нет, выходит новая задача; это возможно при запуске проекта. Повторы и неопределённые результаты доставки обрабатывает общий механизм бота.

Правильный ответ, объяснение, альтернативы, готовый разбор, технология и сложность сохраняются в `generation.editorial`, но не добавляются к публичному тексту задачи. После черновика задача и разбор проходят второй запрос к модели для технической и языковой проверки; стоимость обеих генераций сохраняется. Это не независимое выполнение кода или доказательство правильности. Автоматическая проверка выполнения задач пока не реализована.

Проверка внешних первоисточников для нового формата пока не подключена. Поэтому редакционные слоты используют «Одну полезную штуку» и evergreen-темы; новости, исследования, дайджесты и истории конкретных компаний не генерируются. Ежемесячная подборка и адаптация расписания по статистике остаются будущими возможностями.
