# Creative direction: dvzverev.nvim

Статус: реализовано в первой версии  
Формат: ASCII / Neovim-inspired portfolio

## 1. Тезис

Лендинг выглядит как открытая рабочая сессия Дмитрия, а не как шаблонное портфолио разработчика.

Главная фраза:

> Собираю сайты, ботов и backend, которые работают.

Аудитория: предприниматели, небольшие продуктовые команды и агентства, которым нужен разработчик, способный собрать продуктовый контур целиком.

Единственная цель страницы: довести подходящего человека до сообщения в Telegram.

## 2. Визуальная формула

> Neovim buffer × ASCII-схема × строгий технический постер.

Это не хакерский терминал с кислотно-зелёным текстом. Интерфейс использует узнаваемую структуру редактора — tabline, explorer, номера строк, statusline и command prompt — но остаётся спокойным, типографичным и читаемым.

Главный визуальный приём: весь сайт набран одним специально подготовленным Nerd Font. Выразительность строится размером, ритмом, цветом синтаксиса и композицией, а не тяжёлым display-font или 3D.

## 3. Палитра

| Token      |       Hex | Роль                           |
| ---------- | --------: | ------------------------------ |
| `bg`       | `#090C10` | общий midnight-фон             |
| `panel`    | `#0F141B` | editor buffer                  |
| `text`     | `#D9E2DC` | основной текст                 |
| `muted`    | `#7E8B84` | комментарии и метаданные       |
| `sage`     | `#8BC6A4` | главный акцент и NORMAL mode   |
| `steel`    | `#73A9C2` | ссылки, statusline и data flow |
| `lavender` | `#B8A4D9` | типы и служебные метки         |
| `peach`    | `#D99B7C` | prompt и активные символы      |

Одновременно доминируют midnight, off-white и sage. Остальные цвета работают как синтаксическая подсветка, а не декоративная радуга.

## 4. Типографика

Основной шрифт — локальный `DVZ Mono Nerd`, оптимизированный web-subset JetBrainsMono Nerd Font 3.5.1:

```text
DVZ Mono Nerd / SFMono-Regular / Cascadia Code / Roboto Mono / monospace
```

Причины:

- два WOFF2-файла суммарно около 17,5 KB;
- точная ASCII-геометрия;
- настоящие Nerd Font-глифы для Neovim, Git, терминала, каталогов и социальных ссылок;
- системный fallback и `font-display: swap` сохраняют мгновенное отображение.

Hero использует тот же шрифт в крупном uppercase. Это превращает интерфейсный monospace в display-типографику и делает концепцию цельной.

## 5. Структура

Вместо восьми секций — три сцены.

### 01. `profile.lua`

Hero занимает почти весь первый viewport и выглядит как редактор:

```text
┌ profile.lua ─ work.md ───────────────── main ↑0 ┐
│ explorer │  -- available for selected projects │
│          │  local dmitry = product_engineer     │
│          │                                      │
│          │  СОБИРАЮ САЙТЫ,                      │
│          │  БОТОВ И BACKEND,                    │
│          │  КОТОРЫЕ РАБОТАЮТ.                   │
│          │                                      │
│          │  :написать    :проекты               │
├──────────┴──────────────────────────────────────┤
│ NORMAL  profile.lua                 utf-8  100% │
│ : build product_                                │
└─────────────────────────────────────────────────┘
```

Смысл считывается без знания Neovim. Редакторные детали добавляют характер, но не прячут услугу и CTA.

### 02. `work.md`

Три проекта представлены как раскрывающиеся buffers:

- Реппи;
- Маяк;
- Recall.

Первый проект раскрыт по умолчанию. Нативный `<details>` сохраняет доступность и не требует JavaScript. Внутри показываются роль, проблема и короткий pipeline.

### 03. `contact.sh`

Финальный экран работает как command prompt:

```text
: telegram @zverev_dmitry _                         ENTER ↵
```

Ссылка остаётся обычным `<a>` и работает без JavaScript.

## 6. Motion

Единственное постоянное движение — мигающий cursor в command line. Оно отключается через `prefers-reduced-motion`.

Остальные реакции быстрые и функциональные:

- смена цвета ссылки;
- раскрытие `<details>` силами браузера;
- подсветка имени активного проекта;
- плавный переход по внутреннему anchor, если motion разрешён.

Нет scroll-scrubbing, параллакса, reveal-задержек, canvas, WebGL и загрузочной заставки.

## 7. Responsive

Desktop показывает полный editor chrome и explorer. На планшете explorer скрывается. На mobile остаются:

- tabline;
- buffer;
- номера строк;
- statusline;
- command line.

ASCII-схема hero скрывается на узких экранах, потому что там она конкурирует с главным текстом. Заголовок получает естественные переносы, а весь экран остаётся без горизонтального scroll.

## 8. Производительность как часть стиля

- статический Astro output;
- локальный Nerd Font subset с immutable-кэшированием;
- без React и других client runtimes;
- без hero-изображения;
- без X-ray JavaScript;
- CSS и HTML создают весь первый экран;
- небольшой inline-script генерируется Astro, но полезный контент не зависит от него.

Актуальные бюджеты и замеры находятся в [performance-budget.md](./performance-budget.md).

## 9. Что удалено сознательно

- X-RAY lens;
- Surface/System-слои;
- восемь длинных секций;
- отдельные блоки услуг, процесса, FAQ и about;
- градиентные панели;
- pill-кнопки;
- декоративные карточки;
- формальный маркетинговый текст;
- сложная motion-система.

Информация из удалённых секций не потеряна: стек находится в hero, компетенции — в проектах, личный контакт — в финальном prompt. Остальное можно вернуть только после появления реального контента, который оправдывает новый экран.

## 10. Критерий качества

- за пять секунд понятно, что Дмитрий делает сайты, ботов и backend;
- CTA виден в первом viewport;
- дизайн узнаваем как редактор, но не выглядит пародией на терминал;
- desktop и mobile сохраняют одну визуальную систему;
- страница полностью полезна без JavaScript;
- любой новый элемент должен выглядеть как часть рабочей сессии, а не новая landing-page секция.
