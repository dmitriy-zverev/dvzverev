# dvzverev

Персональный лендинг [www.dvzverev.ru](https://www.dvzverev.ru/) — Neovim-inspired portfolio.

## Stack

- Astro static + TypeScript
- CSS Modules + design tokens
- No client runtime on the landing page
- Vitest + Playwright + axe

## Commands

```bash
npx pnpm@10 install
npx pnpm@10 dev
npx pnpm@10 verify
```
